controller/tree/pawn/world/PRI, both sole-player rosters, inert owned patch,

class before payload reads. Cache only common class identity per call.

an SDK UObject with the exact declared class. Revalidate metadata and fresh
current array membership/count/class before/after each text read, using value
identity of entry references, never Python array-wrapper identity assumptions.

descriptor is targeted separately via _find_prop; no class/instance scanning.
Require exact str payloads before length/slice/repr. Output clips to512
characters, reports full length and clipped flag, escapes the string and
does not interpret templates/HTML. Unknown objects are never repr'd/coerced.

field failure, recheck all guards before another field. Array count/reference
sample and text field totals have separate statuses; empty arrays are
NOT_APPLICABLE with0/0 fields. Known array count alone does not imply text
coverage. Sample beyond4 is explicitly capped. Unknown/changing arrays or
references abort before another target. State changes abort with no repair/
refund and no successful FINAL claim. Each call compares its own baseline;
FINAL unchanged_from_start=True is only printed after full state comparison.
Success means all sampled text fields passed, not rendered previews or gameplay.

Reused _presentation_metadata logs [UVH-PRESENT] SCHEMA during these guarded
reads. New BEGIN/ARRAY/REFERENCE/VALUE/SUMMARY/FINAL/END use [UVH-TEXT].
Repeated schema lines are membership verification, not repeated old traces.
